Мобильное приложение, где учеба превращается в игру: викторины, дуэли с друзьями и конструктор своих тестов.

# В чём суть?
## Цель проекта
Создать платформу, которая превращает обучение в игру. Мы хотим, чтобы пользователи изучали новое, создавали контент и общались через совместные испытания.

## Возможности
- **Викторины** — проходи, зарабатывай очки.
- **Вызовы** — соревнования с друзьями.
- **Конструктор** — создавай свои викторины.
- **Статистика** — отслеживай прогресс.

## Технологии
- **Язык:** Kotlin  
- **UI:** Jetpack Compose, Material 3  
- **Бэкенд:** Firebase (Auth, Firestore, Storage)  
- **Архитектура:** MVVM
